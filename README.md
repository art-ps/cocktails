# Визуальный бар

Интерактивные рецепты коктейлей: выбираете коктейль — и «готовите» его скроллом.
Пока вы листаете, бутылки поднимаются, наклоняются и наливают ингредиенты в стакан;
скролл назад отматывает всё в обратную сторону.

## Как это устроено

- **Three.js**, вся посуда — процедурная (`LatheGeometry`), без внешних ассетов.
- Вся анимация — **чистая функция прогресса скролла** (`src/main.js`):
  пауза, реверс и любая скорость скролла работают автоматически.
- Каждый ингредиент — **отдельный слой жидкости** в стакане, поэтому пропорции
  коктейля видны визуально.
- Демпфирование скролла даёт плавность, HUD показывает текущий ингредиент
  и счётчик миллилитров.

## Запуск

```bash
npm install
npm run dev
```

Продакшен-сборка: `npm run build` (результат в `dist/`).

## Коктейли

Каталог в `src/cocktails.js` — добавить новый коктейль можно простым объектом
(имя, стакан `highball`/`rocks`, ингредиенты с объёмами, цветами и видом бутылки).
